## Sprint Goal

## Sprint Duration

**Start Date:** 22 April 2026  
**End Date:** 10 May 2026

## Product Overview

Kriyanto.ai is a modern AI-focused web product interface built with React and Tailwind CSS.  
The frontend includes a visually polished landing experience with sections such as hero, workflow, trusted companies, pricing, testimonials, FAQ, and call-to-action.

## Frontend Scope

The frontend work will include:

- Navbar with responsive mobile menu
- Hero section with AI-focused headline
- Workflow/process section
- Trusted companies section
- Pricing section
- Testimonials section
- FAQ section
- Final call-to-action section
- Light/dark theme toggle
- Minimalist logo-aligned theme styling
- Smooth hover effects and animations
- Responsive design for mobile, tablet, and desktop
- Accessibility improvements
- Final UI testing and bug fixing
